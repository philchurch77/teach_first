{% comment %} The progress ring. The geometry here and the constants in flow/progress.py describe the same curve: centre (100, 104), radius 76, a 220-degree sweep from 200 to -20, arc length 291.8. The two values below are that arc. Change one and you must change the other. Everything renders at its TARGET value, with the previously shown value in data-prev-* attributes. That is deliberate and it is the reverse of the design prototype: with JavaScript off, or under prefers-reduced-motion, the server-rendered markup is already correct rather than frozen one node behind. The script at the foot of flow.html snaps the ring back to the previous value with transitions suppressed, then releases it, so the fill animates from where the visitor last saw it. The figure is aria-hidden; the stage and percentage beneath it are real text. {% endcomment %}
